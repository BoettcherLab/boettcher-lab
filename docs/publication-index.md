# Publications topic index and article graphics

The owner selected 2020–2026 for recent-paper coverage, including Berkeley and Oregon, and approved a published article figure when no TOC graphic can be obtained. The owner also approved omitting graphics that cannot be retrieved or verified.

The index contains 83 recent publication records, combining the preserved lab bibliography with DOI-deduplicated OpenAlex records for verified author ID `A5032458792` (Shannon W. Boettcher). Articles, reviews, editorials, letters and book chapters are included; conference abstracts, patents without a DOI, datasets, peer-review records and duplicate preprints are not imported. Five earlier curated records remain in the data but are outside the recent-page date filter. The historical source bibliography is retained separately for existing bookmarks.

The 20 topic labels cover the complete recent corpus. Each paper has one or more topics assigned from its title, available abstract and indexed keyword metadata. These are site topic classifications, not claims that every term was supplied as a publisher keyword. `metadata_keywords` retains the indexed keyword terms separately. All 20 topics have matching papers. Selecting bubbles uses intersection (AND), combined with the search box and year selection. Filter selections are encoded in the URL.

OpenAlex supplied the authorship positions used to identify collaborations, with existing verified annotations retained for curated records not returned under the selected publication types. The interface shows only the Collaboration annotation for confirmed non-final-author records; it does not show a group/last-author label or an authorship dropdown.

76 verified graphics are included: 22 explicitly identified TOC graphics and 54 article figures. The other seven records have no image and no placeholder box. Graphics are extracted from public author manuscripts or linked publisher figures; no scientific image was generated. `publication-graphics.json` records DOI, source URL, source page, extraction type and unavailable records. TOCs and ordinary figures are labeled separately in the interface. The three featured papers have verified TOC graphics, and Research topics display the corresponding source graphic when one is available. All graphics are stored locally rather than hotlinked.

The automated sync retains existing graphic fields and assigns keywords using the shared topic rules. Optional `manual_keywords` can override the rules for a record. Topic taxonomy changes should update both `data/publication-topics.json` and its browser copy in `js/publication-topics.js`.

Checks covered 83 rendered recent records, 20 nonempty topic facets, two-topic AND matching, selection focus and accessible pressed state, filter URL reloads, search/year intersections, collaboration annotations, omitted unavailable graphics, and successful decoding of all 76 images. Desktop and mobile layouts were checked at 1440×900, 1366×768, 1024×768, 390×844 and 320×568. The group photo fits the standard desktop viewport without cropping, while narrow layouts retain natural scrolling. Visible molecular labels and Scholar/archive hyperlinks were removed. Script syntax, publication-sync metadata preservation and nullable author IDs were checked as well.
